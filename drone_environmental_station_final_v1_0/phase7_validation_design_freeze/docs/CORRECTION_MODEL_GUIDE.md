# Correction-model guide

Correction is allowed only when bias is reproducible, physically interpretable and independently validated. Keep raw measurements. Split data by independent run or campaign, never by random rows from the same run when temporal dependence would leak information. Begin with transparent linear/physical models. Report domain bounds and reject extrapolation. Compare corrected and uncorrected error on validation and preferably blind-test data. A correction that improves RMSE but creates flight-state-dependent residual bias is not accepted automatically.
