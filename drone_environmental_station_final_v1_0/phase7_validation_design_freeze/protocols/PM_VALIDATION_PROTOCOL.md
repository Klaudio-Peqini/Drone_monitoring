# PM transport/deposition protocol

Use a controlled, sufficiently diluted aerosol and an independently characterized reference instrument. Document aerosol material, density assumption, size distribution, RH, temperature, tubing, residence time and reference location. Evaluate upstream-to-sensor and, where possible, upstream-to-outlet transmission. Use removable witness surfaces or another defensible method for deposition. Never infer size-resolved deposition from bulk PM mass alone without qualification.
