# Changelog

- Consolidated the seven-phase drone environmental-station methodology.
- Added complete Phase 7 validation/design-freeze framework.
- Added highly detailed top-level README and data-governance rules.
- Added experiment registration, metadata validation, time synchronization, response metrics, reference-vs-drone validation metrics, uncertainty aggregation, simple correction-model fitting, quality-flag application, acceptance-gate evaluation and release-freeze tooling.

- Explicitly distinguishes implementation scaffolding from numerically or experimentally validated results.
